# Summary

arXiv 2510.11974 is a CTI benchmark with a dedicated threat-actor / attribution task family.
It was collected at cycle 49 for ONE purpose: to test the primary open question of
`attribution-expressed-confidence-unmeasured` — does any published evaluation measure
EXPRESSED CONFIDENCE on threat-actor attribution? The answer this source gives is **no**, and
the negative is the finding. It is entered as evidence for a negative, not for a positive.

## Task lists differ between the two versions

**v1 (CTIArena), from the `/html/2510.11974v1` discovery fetch** — nine tasks, with metrics:
Root Cause Mapping (RCM), Weakness Instantiation Mapping (WIM), Attack Technique Derivation
(ATD), Exploitation Surface Discovery (ESD), Attack Technique Attribution (ATA) and
Vulnerability Catalog Attribution (VCA) all scored by exact string matching with regex
normalisation; Campaign Storyline Construction (CSC), **Threat Actor Profiling (TAP)** and
Malware Lineage Analysis (MLA) scored by an LLM judge against a structured rubric, reported as
F1.

**v2 (CTIConnect), from the `/abs` abstract verbatim:** "We construct a unified evaluation
environment integrating five heterogeneous CTI sources into 1,860 expert-verified QA pairs
spanning nine tasks across three categories: Entity Linking, Multi-Document Synthesis, and
**Entity Attribution**." and "Extensive experiments on ten state-of-the-art LLMs reveal that the
cross-source semantic gap manifests differently across task categories".

So an attribution-family task is present in BOTH versions.

# THE FINDING FOR THIS BASE: NO CONFIDENCE, CALIBRATION OR ABSTENTION CONSTRUCT

Two fetches on two URL forms — which, as it turned out, served TWO DIFFERENT VERSIONS of the
paper — were each instructed to answer PRESENT/ABSENT and to write ABSENT rather than infer.

**Fetch 1, `arxiv.org/html/2510.11974v1` (= CTIArena), discovery-shaped:**
- calibration statistic (ECE, Brier, reliability diagram, AUROC-of-confidence, selective
  prediction / risk–coverage): **ABSENT**
- any request that the model state a confidence, probability, likelihood or certainty level:
  **ABSENT**
- abstention, refusal, "I don't know", "unknown", "insufficient evidence" measurement: **ABSENT**
- hedging, uncertainty language, token-level probabilities / logprobs: **ABSENT**

**Fetch 2, `arxiv.org/html/2510.11974` unversioned (= CTIConnect v2), exact-string
verification-shaped, searching the ENTIRE document including appendices and prompt templates:**
ABSENT for every one of: `calibration`, `Expected Calibration Error`, `ECE`, `Brier`,
`confidence`, `likelihood`, `abstain`, `abstention`, `I don't know`, `insufficient evidence`,
`uncertain`, `logprob`, `how certain`. The single PRESENT was `probability`, and the sentence
returned for it was about the LLM judge, not about an elicited confidence.

**CONCLUSION, PROPERLY SCOPED:** across both versions' readable bodies, this benchmark scores
its attribution-family tasks by CORRECTNESS ONLY — exact string match for the structured
attribution tasks, LLM-judged rubric F1 for Threat Actor Profiling. It elicits no confidence,
computes no calibration statistic, and measures no abstention. It therefore joins src-0002 and
src-0007 as a third CTI benchmark with an attribution task that does not measure expressed
confidence on it.

# LIMITS THAT MUST TRAVEL WITH THIS ENTRY — READ BEFORE CITING

1. **APPENDIX D WAS NOT READABLE IN EITHER FETCH.** Fetch 1 reported TRUNCATED, cutting off
   mid-sentence inside the Appendix D prompt templates. Fetch 2 reported that it could NOT see
   Appendix D at all, naming "A.4. Magniber Cross-Source Correlation Case Study" as the last
   visible heading (it could see the References). **Prompt templates are exactly where an
   instruction to state a confidence level would live.** Under methodological rule (xvi) an

   for the readable body of two versions and is NOT established for the v1 prompt templates.
   A successor wanting to close this should try the ar5iv render or the KDD 2026 proceedings.
2. **THE TWO FETCHES DISAGREE ON THE JUDGE MODEL** and neither reading is storable as a

   judge guided by a structured rubric…"; fetch 2 returned "we employ GPT-4 as an automatic
   judge guided by a structured rubric." **This base records NO claim about which model judges
   this benchmark.** It is a live question for whoever reads it next, and it is plausibly just
   the version difference — but it was not confirmed by an exact-string ask, so it is not
   asserted here in either direction.
3. **NO PER-MODEL NUMBER FROM THIS SOURCE IS RECORDED**, because none was verified. Nothing in
