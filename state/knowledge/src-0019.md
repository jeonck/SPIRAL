# Summary

This is the official code/data artefact for CTIBench (arXiv 2406.07599 = src-0002), the
benchmark behind this base's CTI-ATE ATT&CK-technique-extraction number (0.6388). It was
collected specifically to discharge `ttp-attack-mapping-reliability` open_questions[3],
which asked: *"Is CTIBench's evaluation code released, and if so does it state the CTI-ATE
matching rule and settle Micro versus Macro?"*

**The answer is: the artefact is released, it ships the CTI-ATE data, and it contains NO
CTI-ATE scorer at all.** The released evaluation notebook covers four of the five tasks and
omits ATE entirely. The CTI-ATE correctness rule is therefore not recoverable from the
artefact any more than it was from the paper, and the Micro-vs-Macro conflict in src-0002
(Section 4.2 says Micro-F1, Table 1's header says Macro-F1) is **not settled by the code**.

This is a negative result, deliberately recorded, because four successive T4 cycles (29,
33, 36, 41) named this as the single named route out of the CTI-ATE leg's defect.

# Key claims

1. **THE REPOSITORY IS THE PAPER'S OFFICIAL ARTEFACT.** `README.md` states verbatim: *"This
   repository contains the data and evaluation scripts for the paper [CTIBench: A Benchmark
   for Evaluating LLMs in Cyber Threat Intelligence](https://arxiv.org/abs/2406.07599)."* It
   also states *"`evaluation` directory contains scripts to evaluate model performance and
   the response for 5 LLMs - ChatGPT3.5, ChatGPT4, Gemini-1.5, LLAMA3-70B, LLAMA3-8B."* and
   points to the HuggingFace mirror `https://huggingface.co/datasets/AI4Sec/cti-bench`.

2. **THERE IS NO CTI-ATE SCORER IN THE RELEASED EVALUATION CODE, AND NO F1 IS COMPUTED
   ANYWHERE IN IT.** `evaluation/evaluation.ipynb` (12,961 bytes) is the only scorer file.
   Its opening markdown cell reads verbatim: *"This notebook contains scripts to evaluate the
   properly formatted responses from large language models (LLMs) for four tasks:"* followed
   by bullets for **CTI-MCQ**, **CTI-RCM and CTI-RCM-2021**, **CTI-VSP** and **CTI-TAA**.
   CTI-ATE is not among them. The notebook's executable functions are exactly four:
   `compute_mcq_accuracy` (accuracy), `compute_rcm_accuracy` (accuracy), `compute_vsp_mad`
   (mean absolute deviation) and `compute_taa_accuracy` (correct & plausible accuracy), plus
   the `threat_actor_connection` / `is_alias_connected` / `is_related_connected` helpers for
   TAA. **The strings `cti-ate` and any F1 computation are absent from the file.** The data
   file `data/cti-ate.tsv` (461,971 bytes) IS shipped, and `cti-ate` IS one of the six
   HuggingFace configs (`cti-ate, cti-mcq, cti-rcm, cti-rcm-2021, cti-taa, cti-vsp`) — so the
   omission is of the scorer only, not of the task data.

3. **THE ABSENCE IS CONFIRMED ACROSS TWO INDEPENDENT MIRROR REPOSITORIES (rule (v)
   discharged).** The HuggingFace dataset card points at `https://github.com/xashru/cti-bench`,
   a *different owner* from the `aiforsec/cti-bench` reached from the paper. Recursive tree
   listings of both were pulled on 2026-07-31. Both carry `evaluation/evaluation.ipynb` at
   **exactly 12,961 bytes**, the identical `data/` set, and the identical
   `evaluation/responses/` set; `xashru` additionally carries a `docs/` project page and
   `docs/assets/pdfs/ctibench.pdf` (3,133,558 bytes). Neither repository contains any other
   scorer file. Byte-identical size across two mirrors makes this the same file, so the
   ABSENT verdict rests on two URL forms and not on one fetch.

# Limitations

- **This establishes absence in the released artefact, not absence of a rule in the authors'
  private pipeline.** CTIBench's authors evidently scored ATE somehow to produce the 0.6388;
  the artefact simply does not show how. No cycle may infer from this that the paper's number
  is wrong — only that its matching rule remains unstated and unrecoverable from both the
  paper and the code.
- **`evaluation/model-prediction.ipynb` (15,803 bytes) was NOT read.** By its name and by the
  README's description it generates model responses rather than scoring them, and there is no
  `cti-ate-responses.tsv` for it to have scored, but this is an inference and a successor
  wanting to close the question completely should read that file. This is the one cheap
  unfinished step on this source.
- The Micro-vs-Macro conflict inside src-0002 is **untouched** by this source. A separate
  rendering of the paper — the NeurIPS 2024 camera-ready at
  `proceedings.neurips.cc/paper_files/paper/2024/file/5acd3c628aa1819fbf07c39ef73e7285-Paper-Datasets_and_Benchmarks_Track.pdf`,
  or the copy shipped in `xashru/cti-bench` at `docs/assets/pdfs/ctibench.pdf` — is the
  obvious next place to look, but **no PDF text extraction is available to this agent**, so
  neither was read and neither may be cited.
- The repository has no release tag or commit pin recorded here; the listing is of branch
  `main` as of 2026-07-31 and could change.
